🚀 QUICK START

1. Clone Repository
   cd /data/data/com.termux/files/home/GamerWingman
   git log --oneline

2. Configure Firebase
   # Download google-services.json from Firebase Console
   # Place in: Assets/Plugins/Android/google-services.json

3. Install Dependencies
   npm install
   cd functions && npm install && cd ..

4. Open in Unity 6 LTS
   Unity Hub → Add Project → GamerWingman
   Open with Unity 6 LTS (2023.2.1f1)

5. Build APK
   File → Build Settings → Android
   Player Settings → Configure Android options
   Build & Run
